# Major Project Report

## Title
Multi-Cloud Monitoring Platform

## Aim
Centralized monitoring of authorized AWS, Azure and GCP infrastructure.

## Objectives
1. Centralized monitoring
2. Real-time performance monitoring
3. Resource health monitoring
4. Metrics collection with Prometheus
5. React interactive dashboard
6. Alert management
7. FastAPI backend
8. Multi-cloud visibility
9. Performance analysis
10. Scalable architecture
11. Authorized account and access monitoring

## Modules
Authentication, cloud accounts, AWS/Azure/GCP resources, metrics, alerts, reports, users, Prometheus and Grafana.

## Expected Outcome
A unified dashboard for infrastructure visibility and authorized account activity across three cloud providers.
